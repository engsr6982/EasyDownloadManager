# EasyDownloadManager - 简易下载器

## 技术栈

| 库/框架           | 作用                   |
|-------------------|------------------------|
| Qt 6.8.x          | 核心 UI 框架           |
| magic-enum        | 枚举反射               |
| sqlitecpp         | SQLite 数据/状态持久化 |
| fmt               | 文本格式化库           |
| spdlog            | 高性能任务日志         |
| glaze             | JSON解析、信封文件实现 |
| curl (http2, ssl) | 核心下载引擎底层实现   |
